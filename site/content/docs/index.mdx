kuizer walks your project folders and lists `node_modules`, `.next`, Cargo `target` directories and other generated folders with their sizes. You select what to remove in an interactive list or with `kuizer clean`. A scan on its own never deletes anything.

It ships as a command line tool with a terminal UI and as a desktop app. Both run the same scan and the same deletion checks.

## What it finds

- **Project artifacts.** Dependency folders, build output, caches and temporary files, matched by built-in rules for JavaScript and its frameworks, Rust, Python, .NET, Maven, Gradle, Swift, CocoaPods, Dart and Flutter, Elixir, Zig, Haskell, CMake, Terraform and Unity.
- **Global caches.** The npm, pnpm, yarn, bun, deno, cargo, pip, uv, Go, Gradle, Maven and Playwright caches, among others.
- **Toolchains.** Installed rustup toolchains, nvm, fnm and volta Node versions, pyenv and uv Python versions, SDKMAN candidates and Go SDKs.
- **Docker and Podman objects.** Dangling images, stopped containers, build cache and volumes no container uses.
- **Git repositories.** Repositories with many loose objects and local branches already merged into the default branch.
- **Duplicate files.** Files with identical contents, found by size and BLAKE3 hash. kuizer reports them and never deletes them.
